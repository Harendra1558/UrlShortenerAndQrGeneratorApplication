Overview
This project provides a URL shortening service along with a feature to generate custom QR codes with styling options. The application allows users to shorten URLs, redirect to the original URL, 
generate custom QR codes with logos and styling, and retrieve analytics for the shortened URLs.

Features
Shorten URLs: Users can shorten URLs, with optional custom aliases and expiration dates.
Redirection: When visiting a shortened URL, the application redirects to the original URL.
QR Code Generation: Generate QR codes with customizable styling, including foreground color, background color, logo, and logo background shapes.
Dynamic QR Code: Generate QR codes for shortened URLs automatically.
Analytics: Retrieve analytics (click count, last accessed date, etc.) for any shortened URL.
